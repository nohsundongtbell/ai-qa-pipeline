# 게시판 요구사항 명세

테스트 케이스(TC)의 추적성 기준이 되는 문서입니다. TC는 여기의 REQ ID를 참조합니다.

## 공통 규칙

- 인증 방식: 서버 세션(쿠키 `connect.sid`)
- 에러 응답 형식: `{ "error": "메시지" }`
- 날짜 형식: `YYYY-MM-DD HH:MM:SS` (서버 로컬 시간)

## 입력 검증 규칙

| 필드 | 규칙 |
|---|---|
| 아이디 | 영문/숫자 4~20자 |
| 비밀번호 | 8자 이상 |
| 닉네임 | 앞뒤 공백 제거 후 2~20자 |
| 제목 | 앞뒤 공백 제거 후 1~100자 |
| 내용 | 앞뒤 공백 제거 후 1자 이상 |

## 요구사항 목록

### REQ-001 회원가입
- 아이디, 비밀번호, 닉네임을 입력해 가입할 수 있다.
- 수락 기준: 유효한 값이면 201 응답, 가입 후 로그인 화면으로 이동한다.
- API: `POST /api/signup` / 화면: `/signup.html`

### REQ-002 아이디 중복 방지
- 이미 존재하는 아이디로는 가입할 수 없다.
- 수락 기준: 409 응답과 오류 메시지를 표시한다.
- API: `POST /api/signup`

### REQ-003 비밀번호 해시 저장
- 비밀번호는 평문이 아닌 bcrypt 해시로 저장한다.
- 수락 기준: DB `users.password_hash`에 평문이 없고, API 응답에 해시가 노출되지 않는다.

### REQ-004 로그인
- 아이디와 비밀번호로 로그인하면 세션이 발급된다.
- 수락 기준: 성공 시 200과 사용자 정보를 반환한다. 실패 시 401을 반환하며, 아이디 오류와 비밀번호 오류를 구분하지 않는다.
- API: `POST /api/login`, `GET /api/me` / 화면: `/login.html`

### REQ-005 로그아웃
- 로그인한 사용자는 로그아웃할 수 있다.
- 수락 기준: 200 응답 후 세션이 종료되어 `GET /api/me`가 `user: null`을 반환한다. 비로그인 상태에서 호출하면 401.
- API: `POST /api/logout`

### REQ-006 게시글 목록 조회
- 누구나 목록에서 제목, 작성자(닉네임), 작성일을 볼 수 있다. 최신 글이 위에 온다.
- API: `GET /api/posts` / 화면: `/`

### REQ-007 목록 페이지네이션
- 목록은 페이지 단위(기본 10개, `limit` 최대 50)로 조회된다.
- 수락 기준: 응답에 `page`, `limit`, `total`, `totalPages`가 포함된다. 잘못된 `page`, `limit` 값은 기본값 또는 허용 범위로 보정한다.
- API: `GET /api/posts?page=&limit=`

### REQ-008 게시글 작성
- 로그인한 사용자만 글을 작성할 수 있다.
- 수락 기준: 유효한 값이면 201과 생성된 글을 반환한다. 작성자는 로그인한 사용자로 기록된다.
- API: `POST /api/posts` / 화면: `/write.html`

### REQ-009 게시글 상세 조회
- 누구나 글의 제목, 내용, 작성자, 작성일(수정일)을 볼 수 있다.
- 수락 기준: 없는 글은 404. 화면에서는 오류 메시지를 표시한다.
- API: `GET /api/posts/:id` / 화면: `/post.html?id=`

### REQ-010 게시글 수정 (본인만)
- 작성자 본인만 글을 수정할 수 있다.
- 수락 기준: 본인이면 200 및 `updated_at` 갱신, 타인이면 403, 없는 글은 404, 검증 실패는 400. 화면의 수정 버튼은 본인에게만 보인다.
- API: `PUT /api/posts/:id`

### REQ-011 게시글 삭제 (본인만)
- 작성자 본인만 글을 삭제할 수 있다.
- 수락 기준: 본인이면 200, 타인이면 403, 없는 글은 404. 삭제 후 목록에서 사라진다. 화면의 삭제 버튼은 본인에게만 보이고, 삭제 전에 확인창이 뜬다.
- API: `DELETE /api/posts/:id`

### REQ-012 비로그인 쓰기 차단
- 로그인하지 않은 사용자는 작성, 수정, 삭제, 로그아웃을 할 수 없다.
- 수락 기준: 해당 API는 401을 반환한다. 화면에서 글쓰기 접근 시 로그인 페이지로 이동한다.

### REQ-013 입력값 검증
- 위 검증 규칙을 위반하면 400과 오류 메시지를 반환한다. 문자열이 아닌 값이나 잘못된 JSON도 400으로 처리한다.
- API: 모든 쓰기 API

### REQ-014 REST API 제공
- 모든 기능을 JSON 기반 REST API로 제공한다.
- 수락 기준: 존재하지 않는 `/api/*` 경로는 404 JSON을 반환한다.

## API 요약

| 메서드 | 경로 | 인증 | 성공 | 실패 |
|---|---|---|---|---|
| POST | `/api/signup` | - | 201 | 400, 409 |
| POST | `/api/login` | - | 200 | 401 |
| POST | `/api/logout` | 필요 | 200 | 401 |
| GET | `/api/me` | - | 200 | - |
| GET | `/api/posts` | - | 200 | - |
| POST | `/api/posts` | 필요 | 201 | 400, 401 |
| GET | `/api/posts/:id` | - | 200 | 404 |
| PUT | `/api/posts/:id` | 필요 | 200 | 400, 401, 403, 404 |
| DELETE | `/api/posts/:id` | 필요 | 200 | 401, 403, 404 |
