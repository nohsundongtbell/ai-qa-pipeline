QA 파이프라인 품질 지표

main 브랜치에 push 될 때마다 CI가 Playwright 테스트(API·UI)를 실행하고 기록한 지표입니다.

아직 기록된 실행이 없습니다. main 브랜치에 push 하면 CI가 첫 기록을 남깁니다.

결함 탐지와 수정 (전체 실행 기준)

테스트 실패를 결함의 대용치로 쓴 값입니다. 앱 결함이 아닌 테스트 문제로 생긴 실패도 포함되며 확정 결함 수가 아닙니다.
